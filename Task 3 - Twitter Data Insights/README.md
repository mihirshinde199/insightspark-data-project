# 🔹 Task 3: Twitter Data Insight Proposal

## 🔢 Objective
To explore and propose how InsightSpark can extract meaningful insights from @CommBank's Twitter account using unstructured data and the Twitter API.

## 📁 Files
- `Commen_wealth_bank.ipynb` — Python notebook for collecting tweets using Twitter API
- `screenshots/` — Visual support from the Twitter UI and analysis steps

## 🔧 Tools & Resources
- Twitter API v2
- Python (requests, pandas)
- Official documentation and use-case articles

## 💡 Proposal Summary
- Collect tweet text, engagement metrics, timestamps, mentions, hashtags
- Perform sentiment analysis and topic modeling
- Use metrics to assess campaign effectiveness, customer sentiment, and recurring topics

## 📚 Suggested Use Cases
- Sentiment trends over time
- Topic clustering using NLP
- Identifying customer pain points and feedback
- Brand engagement metrics

> This task showcases the ability to design insight strategies from unstructured social media data using APIs and basic NLP techniques.
